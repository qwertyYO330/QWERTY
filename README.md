# Telegram-бот с погодой для Йошкар-Олы

Бот публикует прогноз погоды в канал:
- **в 08:00** — погода на **сегодня**;
- **в 21:00** — погода на **завтра**.

По умолчанию канал: `@grishalybitblondinok`.

## Что делает бот

- Берёт прогноз из API Open-Meteo для координат Йошкар-Олы.
- Формирует сообщение по часам: `09:00, 12:00, 15:00, 18:00, 21:00`.
- Добавляет сводку:
  - общее состояние;
  - средняя температура;
  - средняя скорость ветра.

## Запуск

1. Установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Задайте переменные окружения:

```bash
export TELEGRAM_BOT_TOKEN="<TOKEN>"
export TELEGRAM_CHANNEL_ID="@grishalybitblondinok"  # можно не указывать, это значение по умолчанию
```

3. Запустите бота:

```bash
python weather_bot.py
```

## Важно

- Добавьте бота администратором в канал, иначе отправка сообщений не сработает.
- Сервер, где запущен бот, должен работать постоянно (24/7), чтобы задачи на 08:00 и 21:00 выполнялись ежедневно.
